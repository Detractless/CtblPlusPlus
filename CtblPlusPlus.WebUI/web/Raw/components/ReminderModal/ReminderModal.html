Although there are blocks enabled, there are no locks set on any block. A locked block will:

  1. Prevent you from disabling the block
  2. Block your browser if you remove the browser extensions
  3. Stop you from uninstalling the app
  4. Lock certain settings under Settings > Block Strictness

To lock a block:

  1. Click the Blocks tab on the left
  2. Find the block you want to lock and click the lock text (below the toggle that enables the block)
  3. Choose how you want to lock the block in the popup that appears
