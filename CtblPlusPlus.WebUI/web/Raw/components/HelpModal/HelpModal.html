The Unblock button is visible on the block page when:

  1. A block is unlocked
  2. A block is locked with a password or random text
  3. A block has a random text or delay break
  4. A block has an allowance, reward or session break and you enabled the feature that requires this button to be pressed before a break starts

To remove the Unblock button:

  1. Remove any random text or delay breaks set on active block, and
  2. Lock blocks with the Timer, Time Range or Schedule (if scheduled) tabs, or
  3. Lock blocks with a Settings Password and restrict access to the Blocks tab and restrict the changing a block feature

In recent versions of Windows, you may need to manually allow notifications for Cold Turkey Blocker. To do this, please:

  1. Open the Windows Settings app and click System then Notifications & actions
  2. Under Notifications ensure Get notifications from apps and other senders is enabled
  3. Scroll down and select Cold Turkey Blocker in the list of apps
  4. Ensure Notifications, Show notification banners, Show notifications in action center and Play a sound... are enabled

You may also need to disable Focus Assist, or it to Priority Only and add Cold Turkey Blocker to the priority list. To do this:

  1. Open the Windows Settings app and click System then Focus assist
